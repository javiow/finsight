# 브라우저 테스팅 시나리오

매번 브라우저로 기능을 확인할 때 참조하는 체크리스트다. 새 시나리오가 생기면 이 파일에 추가하고, 화면이 실제 라우트로 바뀌면 "적용 대상"을 프로토타입에서 실제 앱으로 옮긴다.

## 현재 적용 대상

랜딩(`app/page.tsx`)과 가격 페이지(`app/pricing/page.tsx`)는 실제 라우트로 구현되어 시나리오 1·1b의 적용 대상이 프로토타입에서 실제 앱으로 옮겨졌다. `npm run dev`로 띄운 뒤 `/`, `/pricing`을 직접 확인한다.

나머지(빈 상태·업로드·대시보드·모바일)는 아직 `src/app`에 실제 화면이 없어 `design/`의 Claude Design 프로토타입을 대상으로 한다. 실제 기능 라우트가 생기면 `docs/DESIGN.md`의 "화면 → 라우트 매핑" 표를 기준으로 같은 시나리오를 해당 라우트(`(dashboard)/dashboard/page.tsx`, `transactions/page.tsx`, `trends/page.tsx`)에 다시 적용한다. 업로드는 독립 라우트가 아니라 대시보드 안 위젯이므로 "빈 상태 → 업로드 → 대시보드"가 한 페이지 안의 상태 전환이 된다.

로그인(`app/login/`)은 아직 구현되지 않았다 — 랜딩·가격 페이지의 모든 CTA가 `/login`으로 보내는데, 지금은 Next.js 기본 404가 뜨는 게 정상이다. 500 에러나 빈 화면이 뜨면 그건 회귀다.

## 사전 준비

프로토타입은 CDN React + Babel로 `.jsx`를 XHR로 읽기 때문에 `file://`로 열면 CORS에 막힌다. 정적 서버로 띄워야 한다.

```
npx --yes serve design -p 5000
```

접속: `http://localhost:5000/FinSight%20Prototype.html`

화면 전환은 페이지 하단 스위처(랜딩·빈 상태·업로드·대시보드·모바일)로 한다. 라우팅이 아니라 컴포넌트 스왑이라 새로고침하면 마지막 라우트가 `localStorage(fs_route)`에서 복원된다.

### Free/Pro 플랜 전환

대시보드는 플랜에 따라 게이팅 UI(LockVeil)가 달라진다. 전환용 Tweaks 패널은 원래 Claude Design 호스트에서만 열리는데, 독립 브라우저에서는 다음을 콘솔(또는 `javascript_tool`)에서 실행해 강제로 연다:

```js
window.postMessage({type:'__activate_edit_mode'}, '*');
```

패널이 우측 하단에 뜨면 "구독 상태" 세그먼트(free/pro)를 클릭해 전환한다. Free 화면 안의 "Pro로 업그레이드"/"전체 히스토리 열기" 버튼을 눌러도 pro로 전환된다(반대 방향은 없음 — free로 되돌리려면 Tweaks 패널을 써야 한다).

## 시나리오

### 1. 랜딩 (`app/page.tsx`, 실제 라우트)
- **트리거**: `http://localhost:<port>/`
- **확인 항목**
  - [ ] 헤더: 워드마크(홈 링크) · "요금제" 링크(`/pricing`으로 실제 이동) · "무료로 시작하기" 버튼
  - [ ] 히어로 카피 + CTA 버튼 2개("무료로 시작하기" · "요금제 보기") — 좁은 화면에서도 어절 중간이 잘리지 않고 자연스럽게 줄바꿈되는지
  - [ ] 도넛 차트 + 카테고리 범례(퍼센트·금액), "예시 데이터입니다" 라벨로 실제 데이터가 아님을 밝힘
  - [ ] 차트 조각·범례 행에 hover 시 반응(툴팁, 배경 강조)
  - [ ] 프라이버시 섹션 3항목(원본 CSV 미전송 / 식별정보 마스킹 / 30일 자동삭제)
  - [ ] 푸터에 "원본 파일은 30일 후 자동 삭제됩니다" + 샌드박스 테스트 카드 안내
  - [ ] 가짜 후기·가입자 수 같은 조작된 사회적 증거가 없는지 (`docs/UX.md`)

### 1b. 가격 페이지 (`app/pricing/page.tsx`, 실제 라우트)
- **트리거**: `http://localhost:<port>/pricing` (또는 랜딩 헤더의 "요금제" 링크)
- **확인 항목**
  - [ ] Free(₩0)·Pro(₩4,900) 카드, Pro에 "추천" 배지 + accent 링 강조
  - [ ] 샌드박스 테스트 카드 번호(`4242 4242 4242 4242`) 안내 문구
  - [ ] "Free로 돌아가도 과거 데이터는 지우지 않고 잠그기만 해요" 문구 (다크패턴 아님을 확인)
  - [ ] Free 카드 CTA는 outline, Pro 카드 CTA는 accent 채움 — 화면당 강조 버튼이 하나인지

### 2. 빈 상태 (명세서 0건)
- **트리거**: 스위처 "빈 상태"
- **확인 항목**
  - [ ] 사이드바: 대시보드 · 업로드 · 거래 내역 · 월별 추이 (실제 앱에서는 "업로드" 항목이 빠진다 — `docs/DESIGN.md` 참고)
  - [ ] 우상단 플랜 배지(Free/Pro) 노출
  - [ ] "아직 올린 명세서가 없어요" 안내 + "CSV 올리기" 버튼
  - [ ] 지원 포맷 캡션(국내 주요 카드사 CSV · CP949/UTF-8 자동 감지)

### 3. 업로드
- **트리거**: 스위처 "업로드"
- **확인 항목**
  - [ ] 드래그앤드롭 영역 + "파일 선택" 버튼
  - [ ] 파일 제약 캡션(.csv · 최대 10MB · CP949/UTF-8)
  - [ ] 프라이버시 설명 카드(랜딩과 동일 3항목) 재노출
  - [ ] 파싱 실패 안내 문구("컬럼을 못 찾으면 분석을 진행하지 않고 어떤 컬럼이 없었는지 알려드려요")

### 4. 대시보드 — Free 플랜
- **트리거**: 스위처 "대시보드" → Tweaks 패널에서 구독 상태를 free로 전환
- **확인 항목**
  - [ ] 상단 배지 "Free 플랜"
  - [ ] StatCard 3종(총 지출·거래 건수·가장 큰 카테고리) — 플랜 무관하게 노출
  - [ ] "이번 달 눈에 띄는 변화": 인사이트 1개만 원본 노출, 나머지는 블러 + LockVeil("인사이트 N개가 더 있어요" · "Pro로 업그레이드")
  - [ ] "월별 추이": 전체 LockVeil("월별 추이는 Pro 기능이에요" · PRO 배지)
  - [ ] 거래 내역: `N/18건 표시`로 8건만 노출 + "이전 달 내역은 잠겨 있어요" 안내 + "전체 히스토리 열기 →" 버튼

### 5. 대시보드 — Pro 플랜
- **트리거**: 위 상태에서 Tweaks 패널 구독 상태를 pro로 전환 (또는 Free 화면의 업그레이드 버튼)
- **확인 항목**
  - [ ] 상단 배지 "Pro 플랜"
  - [ ] 인사이트 5개 전체 노출, LockVeil 없음
  - [ ] 월별 추이 바 차트(최근 5개월) 정상 렌더링, 당월 바만 포인트 컬러
  - [ ] 거래 내역 `18/18건 표시`로 전체 노출

### 6. 모바일 참고 화면
- **트리거**: 스위처 "모바일"
- **확인 항목**
  - [ ] 폰 프레임 2종: "모바일 · 요약"(총 지출·도넛·인사이트), "모바일 · 거래 내역"(리스트형)
  - [ ] 현재 플랜(Free/Pro) 배지가 요약 화면 상단에 반영됨
  - [ ] Free일 때 인사이트 카드 하단에 "+N개 더" · "Pro로 보기 →" 노출
- **알려진 한계**: 이 화면은 실제 뷰포트 축소가 아니라 고정 크기 폰 프레임 목업이다(`docs/DESIGN.md`: "라우트가 아니다. 반응형 검증용 참고 화면"). 실제 좁은 화면에서의 리플로우 검증에는 부적합 — 실제 라우트가 생긴 뒤에는 브라우저 DevTools 반응형 모드나 실기기로 직접 확인한다. 이 자동화 환경에서는 `resize_window`로 브라우저 창을 줄여도 페이지 `window.innerWidth`가 그대로인 경우가 있어 신뢰할 수 없었다.

## 자동화 시 주의사항

- **`resize_window`와 Tweaks 패널을 동시에 쓰지 않는다.** 창 리사이즈 직후 Tweaks 패널이 열린 상태로 남아 있으면 해당 탭이 스크린샷/`read_page` 호출에 응답하지 않게 되는 현상이 관찰됐다(JS 실행 자체는 되지만 idle 감지가 걸림). 막히면 새 탭을 만들어 이어가는 게 가장 빠르다.
- Tweaks 패널은 열려 있는 동안 `ResizeObserver`가 계속 도는 구조라, 확인이 끝나면 우상단 `✕`로 바로 닫는다.
- 플랜을 pro로 되돌려놓고 세션을 끝내는 게 기본값과 일치해서 다음 테스트가 깔끔하다(`TWEAK_DEFAULTS.plan`이 `"pro"`).

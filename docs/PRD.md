# PRD: FinSight

## 목표

카드 명세서 CSV를 올리면 몇 분 안에 "이번 달 어디에 얼마를 썼는지"를 카테고리별로 보여주고, 눈에 띄는 소비 변화를 문장으로 짚어준다.

## 사용자

가계부를 쓰고 싶지만 손으로 분류하다 포기한 개인 소비자. 카드사 웹사이트에서 명세서를 CSV로 내려받을 수 있고, **한 달에 한 번** 앱에 들어온다. 카드를 2장 이상 쓰는 경우가 흔하다.

이 사용 리듬이 제품 설계를 좌우한다. 세션 간격이 한 달이라 매번 처음 쓰는 것처럼 느껴지므로, 대시보드는 설명 없이 즉시 읽혀야 한다.

## 핵심 기능

1. **CSV 업로드 → 자동 파싱** — 카드사마다 다른 헤더와 인코딩(CP949)을 LLM 헤더 매핑으로 흡수한다. 사용자는 그냥 올리기만 한다.
2. **카테고리 자동 분류** — 가맹점명을 12개 카테고리로 분류하고, 틀린 건 사용자가 고칠 수 있다. **고친 내용은 다음 달 명세서에도 유지된다.**
3. **카테고리별 지출 요약** — 총 지출, 도넛 차트, 거래 내역 테이블. 같은 달에 올린 카드 여러 장은 합산해서 보여준다.
4. **AI 인사이트** — 집계 결과를 바탕으로 소비 변화를 문장으로 짚어준다. Free는 1개 미리보기, Pro는 전체.
5. **월별 추이 비교** (Pro) — 여러 달 데이터를 쌓아 지출 변화를 본다.
6. **구독 결제** — Polar 체크아웃과 고객 포털.

## MVP 제외 사항

- **LLM 매핑 실패 시 컬럼 수동 지정 UI** — v1.1. UI 구현 비용이 크다. MVP는 명확한 실패 안내로 대체한다.
- **예산 설정·초과 알림** — v1.2. 알림 인프라가 별건이다.
- **은행 계좌 내역(수입) 지원** — v1.1. 카드 명세서에 집중한다.
- **원본 CSV 재다운로드** — Storage 직접 접근을 열지 않기 위해 제공하지 않는다.
- **팀·다중 사용자 기능** — 개인 사용자 전용이다.

## 요금제

| | Free | Pro |
|---|---|---|
| 업로드·파싱·분류 | ✅ | ✅ |
| 카테고리 요약·거래 테이블 | 최근 1개월 | 전체 히스토리 |
| AI 인사이트 | 미리보기 1개 | 전체 |
| 월별 추이 | ❌ | ✅ |

**"최근 1개월"은 그 유저의 가장 최근 거래가 속한 달**이며, 그 달에 올린 모든 카드를 합산한다. 파일 1건 기준이 아니다 — 카드 2장을 쓰는 사용자가 두 번째를 올리는 순간 첫 번째가 잠기면 버그로 읽힌다.

Free로 떨어져도 과거 데이터는 삭제하지 않고 잠그기만 한다.

## 프라이버시 — 제품 약속이자 전환 레버

"내 카드 내역을 AI에 보낸다"는 거부감이 가입 전환의 1차 장벽이다. 다음을 랜딩과 업로드 화면에 같은 문구로 고지한다.

- 원본 CSV 전체를 외부 모델에 보내지 않는다. 매핑 판별용 **비식별화된 미리보기**, 분류용 **가맹점명**, 인사이트용 **집계 숫자**만 목적별로 보낸다.
- 카드번호·계좌·연락처 같은 식별정보는 전송 전에 마스킹한다. 애초에 날짜·가맹점·금액 세 가지만 추출하므로 DB에도 들어가지 않는다.
- 원본 파일은 private Storage에 **30일 보관 후 자동 삭제**한다. 분석 결과는 남는다.

## 디자인

- 다크 모드 고정, 미니멀
- 무채색 + 포인트 컬러 1가지
